Generated by `php spec/build-inventory.php` from https://api.close.com/api/openapi.json on 23 September 2026. Spec version 1.0.0.

**302 operations across 159 paths and 64 tags.** 127 have a typed 2xx response schema and 175 do not; of the 110 that take a request body, 54 are typed. The untyped half is why this package is hand-written rather than generated — see DESIGN.md.

**This inventory is not complete, because the spec is not.** `POST /data/search/` — the

nowhere in it. Treat an absence here as a question rather than an answer.

collection path, and `tests/Resource/ResourceTest.php` enumerates every method and URL the
resources produce. Everything else is reachable through `Close::transport()`.
